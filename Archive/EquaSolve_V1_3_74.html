Developer

EquaSolve was designed and developed by Dr. Omar Al-Abbasi, Associate Professor of Mechanical Engineering at the University of Bahrain, whose work focuses on computational thermo-fluids, heat transfer, and energy systems modeling.

Parts of the implementation were developed with the assistance of AI tools (Claude, Anthropic), used as a coding and engineering knowledge aid throughout the development process.

💧 Water/Steam Property Functions (IAPWS-IF97)

Reference state: hf=200 kJ/kg, sf=1.0 kJ/kg·K at 0°C (IIR — matches Cengel & Boles Tables A-11 to A-16). R-404A uses ASHRAE (hf=0, sf=0 at −40°C). Accuracy: PR-EOS, expect ≈1–3% deviation from tabulated data.

💨 Air — Two Property Models
Air can be evaluated two ways. Pick the one that matches your reference. Both use your active input units (Units tab).
1 · Ideal-gas, Table A-17 (matches Cengel & Boles / EES "Air")
Temperature-only functions — exact A-17 tabulated values with interpolation. Use when a problem is keyed to the textbook air tables. Entropy carries no pressure term; add it yourself for entropy at a state.
h_T_air(T) u_T_air(T)Enthalpy / internal energy [kJ/kg]
so_air(T)Standard-state entropy s°(T) [kJ/(kg·K)]
Pr_air(T) vr_air(T)Relative pressure / relative volume [—]
T_h_air(h) T_u_air(u)Inverse — temperature from h or u [K]
T_Pr_air(Pr) T_so_air(s°)Inverse — temperature from Pr or s° [K]
Entropy at a state: s = so_air(T) − R·ln(P/P_ref) with R = 0.287 kJ/(kg·K). Isentropic process: Pr2 = Pr1·(P2/P1), then T2 = T_Pr_air(Pr2).
2 · Real-gas, Peng-Robinson EOS
Two-property functions — full (P,T) dependence including real-gas departure. More rigorous; differs from A-17 by roughly 0.3% at moderate pressure. Entropy already includes the pressure term.
h_PT_air(P,T) s_PT_air(P,T)Enthalpy / entropy at (P,T)
h_TP_air(T,P) s_TP_air(T,P)Same — reversed argument order
h_Ps_air(P,s) T_Ps_air(P,s)From (P,s) — e.g. isentropic exit state
u_PT_air(P,T) v_PT_air(P,T)Internal energy / specific volume
Note: h_T_air takes one argument (T only, ideal gas); h_PT_air takes two (P and T, real gas). The argument count tells you which model is active.
🔥 Combustion Property Functions
Unified h_X / s_X — argument count selects the model
h_X(T) and s_X(T) return ideal-gas molar properties (kJ/kmol, kJ/kmol·K) on the Cengel A-26 reference: h°f + Δh̄(T), s°(T) at 1 atm. h_X(P,T) and s_X(P,T) route to the existing PR-EOS real-fluid model where one exists. Argument units honor your input unit setting just like h_PT.
Products and Diatomics — Valid to 6000 K
N2O2H2 COCO2H2O OHNONO2
Gaseous Fuels — Valid 273–1500 K (CH4 to 6000 K)
CH4C2H6C3H8 C4H10C2H2C2H4 C8H18
h_CO2(T) h_H2O(T) h_N2(T)Absolute molar enthalpy h°f + Δh̄(T) [kJ/kmol]
s_CO2(T) s_H2O(T) s_N2(T)Absolute molar entropy s°(T) at 1 atm [kJ/(kmol·K)]
h_CO2(298.15) = -393520= hf at standard state
s_CO2(298.15) = 213.80= s°(298.15 K) from Cengel A-26
h_CO2(P, T) s_CO2(P, T)2 args → PR-EOS real fluid (kJ/kg, kJ/(kg·K))
Formula ↔ word-form aliases (CO2, CH4, C2H6, C3H8, C4H10, N2, O2, H2)
h_CH4(T) ≡ h_methane(T)Both spellings route to the same dispatcher
h_N2(P, T) ≡ h_nitrogen(P, T)2-arg form → PR-EOS nitrogen
Partial-pressure entropy correction (Dalton's law)
R_u = 8.314           // kJ/(kmol·K)
P_ref = 101.325 [kPa]
y_CO2 = N_CO2 / N_total

s_CO2_partial = s_CO2(T) - R_u * ln(y_CO2 * P_total / P_ref)
For ideal-gas mixtures, partial-pressure entropy is s_i = s°_i(T) − R·ln(P_i/P_ref). Apply this when computing entropy generation across a combustion reactor.
Liquid Fuel Formation Enthalpies (kJ/kmol at 298.15 K)
For combustion problems with liquid fuels entering at 25 °C, use these built-in constants directly on the RHS — at inlet T = T_ref, sensible Δh̄ = 0 so only the formation enthalpy contributes:
hf_C8H18l ≡ hf_octane_ln-Octane: −249,950 (Cengel A-26)
hf_C7H16l ≡ hf_heptane_ln-Heptane: −224,430
hf_C12H26l ≡ hf_dodecane_ln-Dodecane (Diesel surrogate): −347,830
hf_C6H6l ≡ hf_benzene_lBenzene: +49,030 (positive hf)
hf_C6H14l ≡ hf_hexane_ln-Hexane: −198,700 (NIST)
hf_C5H12l ≡ hf_pentane_ln-Pentane: −173,500 (NIST)
hf_CH3OHl ≡ hf_methanol_lMethanol: −238,660
hf_C2H5OHl ≡ hf_ethanol_lEthanol: −277,690
Liquid Fuel Example — Cengel 15-8(a): C8H18(l) + 100% air
// C8H18(l) + 12.5(O2 + 3.76 N2) → 8 CO2 + 9 H2O + 47 N2
N_CO2 = 8
N_H2O = 9
N_N2  = 47

N_CO2*h_CO2(T_prod) + N_H2O*h_H2O(T_prod) + N_N2*h_N2(T_prod) = hf_C8H18l
Solves to T_prod ≈ 2394 K (Cengel textbook: 2395 K). Reactants at 25 °C so the liquid fuel contributes only its formation enthalpy. For preheated liquid fuels, add a sensible-heating term: hf_C8H18l + Cp_C8H18l*(T_in - 298.15) using a manually declared liquid Cp.
Adiabatic Flame Temperature — CH4 + 100% air
N_CO2 = 1
N_H2O = 2
N_N2  = 2 * 3.76

N_CO2*h_CO2(T_prod) + N_H2O*h_H2O(T_prod) + N_N2*h_N2(T_prod) = h_CH4(T_react)
T_prod is auto-recognized as a temperature variable (dimension inference) and displayed in your preferred unit. Solves to ~2326 K for T_react = 298.15 K.
Note: combustion molar properties (1 arg) and PR-EOS specific properties (2 args) have different units (kJ/kmol vs kJ/kg) — keep your energy-balance accounting consistent.
⊕ Exergy Functions
Dead State — Required for all exergy functions
T0 = 25 + 273.15
Dead-state temperature in Kelvin — must be named T0
P0 = 0.101325
Dead-state pressure in MPa — must be named P0
Define T0 and P0 anywhere in the equation block. All exergy functions read them automatically. Dead-state properties (h₀, s₀, u₀, v₀) are computed internally — never define them manually.
Flow Exergy — open systems [kJ/kg]
exf(h1, s1)
Auto-detected as (h,s) mode when variable names start with h/s or units are kJ/kg · works for any phase including two-phase
ψ = (h − h₀) − T₀·(s − s₀)
exf(T1, P1)
Default (T,P) mode — for superheated/compressed single-phase states · h₀, s₀ computed internally
ψ = (h(T,P) − h₀) − T₀·(s(T,P) − s₀)
exf_R134a(h1, s1)
Fluid-specific flow exergy — use when fluid selector is set to a different fluid · all 36 fluid aliases supported · same (h,s) / (T,P) auto-detection
Non-flow Exergy — closed systems [kJ/kg]
ex(T1, P1)
2 args → (T,P) mode · properties computed internally from IF97/EOS
Φ = (u − u₀) + P₀·(v − v₀) − T₀·(s − s₀)
ex(u1, v1, s1)
3 args → supply u [kJ/kg], v [m³/kg], s [kJ/kg·K] directly · use for two-phase or when properties are already known
Φ = (u − u₀) + P₀·(v − v₀) − T₀·(s − s₀)
Heat Exergy [kJ/kg or kW]
exheat(Q, T_boundary)
Exergy associated with heat transfer Q at a boundary temperature · T_boundary in K · Q and result in same units (kJ/kg or kW)
Ė_Q = Q·(1 − T₀ / T_boundary)
T_boundary > T₀result positive — heat above dead state carries usable exergy
T_boundary < T₀result negative — heat below dead state (e.g. evaporator) costs exergy
exheat(Q, T0)always returns 0 — heat at the dead state has zero exergy
Exergy Destruction
ex_dest = W_in − Δexf
Compressor / pump · W_in is work input per unit mass · Δexf = exf_out − exf_in
Ẋ_dest = Ẇ − ṁ·(ψ₂ − ψ₁) > 0 for irreversible processes
ex_dest = exheat(Q, T_H) − Δexf
Heat exchanger / boiler · exergy supplied minus exergy gained by fluid
ex_dest = exf_in − exf_out
Throttle valve / irreversible expansion · no work, no heat · destruction equals drop in flow exergy
The bar chart in the results panel shows exergy destruction for every variable whose name contains ex_dest. Negative values flag automatically with a ⚠ warning — check sign convention.
⊕ Pipe Flow Functions (Darcy-Weisbach)
Reynolds Number & Friction Factor
Re_pipe(V, D, nu)
Reynolds number
Re = V · D / ν
f_moody(Re, eD)
Darcy friction factor — Colebrook-White (iterative)
Laminar (Re < 2300): f = 64 / Re
Turbulent: 1/√f = −2 log₁₀(ε/3.7D + 2.51 / Re√f)
f_moody_approx(Re, eD)
Swamee-Jain explicit approximation (~3% error)
f = 0.25 / [log₁₀(ε/3.7D + 5.74/Re⁰·⁹)]²
Head Loss & Pressure Drop
hf_darcy(f, L, D, V)
Head loss [m]
h_f = f · (L/D) · V² / 2g
dP_darcy(f, L, D, V, rho)
Pressure drop [Pa]
ΔP = f · (L/D) · ½ρV²
V_darcy(hf, f, L, D)
Velocity from known head loss [m/s]
V = √(2g · h_f · D / f · L)
V [m/s] · D [m] · L [m] · nu [m²/s] · eD = ε/D [-] · rho [kg/m³]
🌡 Heat Transfer Correlations
Dimensionless Numbers
Pr_num(mu, cp_J, k)
Prandtl number
Pr = μ · cp / k
Ra_num(beta, dT, L, nu, alpha)
Rayleigh number
Ra = g · β · ΔT · L³ / (ν · α)
Gr_num(beta, dT, L, nu)
Grashof number
Gr = g · β · ΔT · L³ / ν²
Forced Convection — Internal Pipe Flow
Nu_pipe(Re, Pr)
Pipe flow Nusselt — uses f_moody internally
Laminar (Re < 2300): Nu = 3.66
Turbulent — Gnielinski: Nu = (f/8)(Re−1000)Pr / [1 + 12.7√(f/8) (Pr²/³−1)]
Nu_pipe_f(Re, Pr, f)
Gnielinski with explicit friction factor f
Same as Nu_pipe but uses supplied f directly
Forced Convection — External Flat Plate
Nu_flatplate(Re_L, Pr)
Average Nusselt — mixed boundary layer (Re_cr = 5×10⁵)
Laminar: Nu = 0.664 · Re_L^½ · Pr^⅓
Mixed BL: Nu = (0.037 · Re_L^0.8 − 871) · Pr^⅓
Nu_flatplate_lam(Re_x, Pr)
Local laminar Nusselt at position x
Nu_x = 0.332 · Re_x^½ · Pr^⅓
Nu_flatplate_turb(Re_x, Pr)
Local turbulent Nusselt at position x
Nu_x = 0.0296 · Re_x^0.8 · Pr^⅓
Forced Convection — External Bodies
Nu_cylinder(Re_D, Pr)
Cross-flow over cylinder — Churchill-Bernstein
Nu = 0.3 + 0.62·Re^½·Pr^⅓ / [1+(0.4/Pr)^⅔]^¼ · [1+(Re/282000)^⅝]^⁴⁄⁵
Nu_sphere(Re_D, Pr)
Flow over sphere — Whitaker (3.5 ≤ Re ≤ 7.6×10⁴)
Nu = 2 + (0.4·Re^½ + 0.06·Re^⅔) · Pr^0.4
Nu_tube_bank(Re_max, Pr, N_rows)
Bank of tubes — Zukauskas; Re_max based on min free-flow area
Nu = C · Re_max^m · Pr^0.36 · F_N (C, m depend on Re range)
Natural Convection
Nu_vertplate(Ra_L, Pr)
Vertical plate — Churchill-Chu (entire Ra range)
Nu = [0.825 + 0.387·(Ra / (1+(0.492/Pr)^(9/16))^(16/9))^⅙]²
Nu_horizcyl(Ra_D, Pr)
Horizontal cylinder — Churchill-Chu
Nu = [0.60 + 0.387·Ra_eff^⅙]²
Nu_horizplate(Ra_L, hot_up)
Horizontal plate (hot_up=1: heated upper / cooled lower)
hot_up=1, Ra ≤ 10⁷: Nu = 0.54·Ra^¼
hot_up=1, Ra > 10⁷: Nu = 0.15·Ra^⅓
hot_up=0 (heated lower): Nu = 0.27·Ra^¼
Convection Coefficient & Heat Exchangers
h_conv(Nu, k, L)
Convection coefficient from Nusselt number [W/m²K]
h = Nu · k / L
LMTD(T_h1, T_h2, T_c1, T_c2)
Log-mean temperature difference — counterflow [K]
ΔT₁ = T_h1 − T_c2, ΔT₂ = T_h2 − T_c1
LMTD = (ΔT₁ − ΔT₂) / ln(ΔT₁/ΔT₂)
